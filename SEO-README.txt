AMARPDF SEO SETUP
=================

This build includes on-page SEO, canonical URL, Open Graph/Twitter metadata,
WebSite/WebApplication/FAQ structured data, crawlable PDF + image tool content,
and a sitemap.xml.

IMPORTANT FOR GITHUB PAGES PROJECT SITES
-----------------------------------------
The live AmarPDF URL is:
https://sajibnath360.github.io/projects.github.io/amarpdf/

The robots.txt included in this folder documents the correct crawl policy and
sitemap. GitHub Pages serves robots.txt from the site origin root, so for the
strongest setup also place this exact robots.txt at the repository root:
https://sajibnath360.github.io/robots.txt

SITEMAP
-------
Submit this URL in Google Search Console:
https://sajibnath360.github.io/projects.github.io/amarpdf/sitemap.xml

INDEXING
--------
In Google Search Console, use URL Inspection for the AmarPDF URL and choose
Request Indexing after publishing. Indexing and ranking are controlled by
Google and are not guaranteed by metadata alone.
