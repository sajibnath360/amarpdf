AmarPDF SEO deployment notes
============================

Canonical site:
https://sajibnath360.github.io/amarpdf/

This build includes:
- descriptive title and meta description
- canonical URL, robots directives and social metadata
- WebSite, WebApplication/SoftwareApplication-style, WebPage and FAQ structured data
- crawlable on-page content for PDF editor, PDF tools and image resizer searches
- practical How It Works content
- sitemap.xml
- robots.txt inside the app folder for reference
- root-level robots.txt for GitHub Pages project-site crawling
- mobile-friendly responsive UI and browser-local processing messaging

Important:
No HTML/CSS/structured-data change can guarantee a #1 Google position. Google ranking depends on relevance, content quality, indexing, competition, links, site reputation, performance and many other signals. Google also does not guarantee that structured data will produce a rich result.

After uploading:
1. Open the live AmarPDF URL and confirm it loads correctly.
2. In Google Search Console, add/verify the site property.
3. Use URL Inspection on the live AmarPDF URL.
4. Request indexing after the final deployment.
5. Submit this sitemap URL:
   https://sajibnath360.github.io/amarpdf/sitemap.xml
6. Recheck indexing and Core Web Vitals after Google has crawled the updated page.

Do not keyword-stuff the page or create doorway pages. Keep the visible copy useful and natural.
