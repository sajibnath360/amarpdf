# AmarPDF — Premium PDF Tools

Browser-only PDF utility website for GitHub Pages or local use.

## Edit PDF workflow

1. Open **Edit PDF** and choose a PDF.
2. Edit text directly on the page.
3. Click **Apply Edit**.
4. AmarPDF generates a fresh PDF with `pdf-lib` and validates the `%PDF-` signature before enabling download.
5. **Download latest PDF** is a separate real `<a download>` link backed directly by the latest PDF Blob URL.
6. Every subsequent **Apply Edit** replaces the previous downloadable version with the newest export.

The export path is intentionally independent from the button styling: Apply Edit only generates the PDF; the adjacent Download link downloads the latest successfully generated bytes.

## Notes

- Processing is performed in the browser; no PDF is uploaded by this project.
- PDF.js is used to read/render editable text overlays.
- pdf-lib is used to serialize the edited document to PDF bytes.
- Complex/scanned PDFs may require OCR or may have layout limitations.

### Image Resize
AmarPDF includes a browser-only high-quality Image Resize tool with custom pixel dimensions, aspect-ratio control, long-edge presets, print-size + DPI controls, custom DPI, JPG/PNG/WebP output, progressive downsampling, and batch ZIP export.
